Deskripsi serta teknologi di `src/data/portfolio.js` diringkas dari sumber tersebut, bukan dari tebakan nama repo. Dua proyek pertama ditandai sebagai course project; automation sebagai personal experiment. Repo tidak dijalankan atau diaudit pada sesi ini; tidak ada klaim performa, jumlah pengguna, kualitas keamanan, atau deployment aktif.

Semua aksi saat ini menuju repository yang terverifikasi. URL demo tidak diisi karena layanan live belum diverifikasi. Tidak ada screenshot aplikasi yang diambil; visual monogram pada halaman adalah dekorasi buatan untuk layout. Web Porto tidak lagi menjadi kartu utama agar ruang digunakan untuk tiga contoh yang lebih bervariasi.
